# Visuels de la page d'accueil

Fichiers attendus ici :

| Fichier | Utilisation |
| --- | --- |
| `hero.jpg` (ou `.png`) | Visuel principal du hero, `components/home/Hero.tsx` |
| `advantages.jpg` (ou `.png`) | Section "Avantages", `components/home/Advantages.tsx` |

Tant qu'un fichier est absent, la section correspondante affiche une image de
placeholder (`picsum.photos`) : déposer le fichier ne suffit pas à lui seul,
il faut aussi que le code soit mis à jour pour pointer dessus.
