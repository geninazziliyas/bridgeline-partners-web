# Dépôt de visuels

Dossier "boîte de réception" pour n'importe quelle photo destinée au site,
quand sa destination finale n'est pas encore décidée (bureaux, page Room,
autre section à venir...).

Déposez le fichier ici avec un nom clair (ex. `bureau-geneve.jpg`,
`room-interieur.jpg`), puis signalez-le : le fichier est ensuite déplacé vers
son emplacement définitif (`public/home/`, `public/team/`, etc.) et le code
mis à jour pour pointer dessus. Rien ne s'affiche automatiquement tant que
ce câblage n'est pas fait.
